# نقشه‌ی راه

| هفته | کار | خروجی |
|---|---|---|
| ۱ | ۱۰ پیام مستقیم + ۵ مصاحبه | جدول مصاحبه |
| ۲ | ۵ مصاحبه‌ی دیگر + تست دستی با گوگل‌فرم | تصمیم: ادامه / تغییر ایده |
| ۳ | (اگر ادامه) مرحله ۱ امنیت و تصحیح سمت سرور | بک‌اند امن |
| ۴ | مدل Organization/Membership، پنل مربی ساده | ساخت آزمون و دعوت شاگرد |
| ۵ | حل آزمون برای شاگرد + گزارش | MVP قابل‌استفاده |
| ۶ | پایلوت رایگان با ۲–۳ موسسه | بازخورد واقعی |
| ۷–۸ | اصلاح، قیمت‌گذاری، اولین مشتری پولی | درآمد اول |

## نقطه‌های تصمیم
- پایان هفته ۲: کمتر از ۲ پایلوت؟ ایده یا مشتری را عوض کن.
- پایان هفته ۶: موسسه‌ها از ابزار استفاده می‌کنند و برمی‌گردند؟ پس قیمت بگذار.

## ریسک‌ها
- بازار کوچک است: با ۵–۱۰ مشتری شروع کن.
- فروش B2B کند است: پایلوت رایگان یک‌ماهه.
- سؤال ذهنی SMC: فقط سؤال‌های عینی را در MVP بگذار.
