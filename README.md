# TradingQuiz Pro: ابزار سنجش مهارت برای موسسه‌های آموزش ترید

## ایده در یک جمله
پلتفرمی که موسسه‌ها و مربی‌های ترید با آن آزمون‌های چارت‌محور می‌سازند، به شاگردها می‌دهند و **نمره‌ی قابل‌اعتماد و گزارش پیشرفت** می‌گیرند.

## مشکل (فرضیه، باید با مصاحبه تأیید شود)
- مربی‌ها و موسسه‌ها شاگردهایشان را با گوگل‌فرم، تلگرام یا اسلاید می‌سنجند؛ دستی، کند و غیرقابل‌اعتماد.
- نمی‌توانند نشان دهند شاگردها واقعاً پیشرفت کرده‌اند (و این برای بازاریابی‌شان مهم است).
- شاگرد هیچ مدرک قابل‌ارائه‌ای از مهارتش ندارد.

## مشتری
- **خریدار:** مدیر موسسه یا مربی مستقل ترید (فارکس، کریپتو، بورس).
- **کاربر نهایی:** شاگردهای آن‌ها.

## تفاوت با رقبا
| رقیب | ضعفش |
|---|---|
| Google Forms / Typeform | تصویر چارت و گزارش مخصوص ترید ندارد |
| TradingView Replay | آزمون و نمره و گزارش مربی ندارد |
| دوره‌سازها (Teachable, Moodle) | سنگین، عمومی و بدون سؤال چارت‌محور |

## اصل‌های محصول
1. **سؤال‌ها تا حد ممکن عینی باشند** (مثلاً نتیجه‌ی قیمتی قابل‌اندازه‌گیری)، نه نظر شخصی مربی.
2. **تصحیح فقط سمت سرور.** کلاینت هرگز جواب درست را نمی‌بیند.
3. **بدون جایزه نقدی و بدون پرداخت بین کاربران.** فقط اشتراک موسسه.
4. **اول مصاحبه، بعد کد.** MVP فقط بعد از تأیید تقاضا ساخته می‌شود.
